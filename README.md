# PionHRM

## Introduction
This project is a web-based Human Resource Management System developed to support employee management, attendance tracking, payroll, and related HR operations.

The project was developed as a graduation project/business analysis practice project.

---

## Features
- Employee management
- Attendance management
- Salary management
- Dashboard & reporting

---

## Technologies Used
- Frontend: HTML, CSS, JavaScript
- Backend: PHP
- Database: MySQL
- Tools: XAMPP, Figma

---

## Business Analysis Documents
The document file located in the Documents folder includes:
- Software Requirement Specification
- Use Case Diagram
- Use Case Description
- Activity Diagram
- Sequence Diagram
- Class Diagram
- Database Design
- UI/UX Design

---

## Project Structure
- /SourceCode        -> Source code project
- /Documents         -> BA documents

---

## Installation Guide

1. Install XAMPP
2. Copy project folder into `htdocs`
3. Import database `.sql` file into phpMyAdmin
4. Start Apache and MySQL
5. Open browser and access:

```bash
http://localhost/PionHRM
```
